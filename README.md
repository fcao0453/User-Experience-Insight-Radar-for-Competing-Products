# 观微 · 竞品研究工作台

该仓库包含程序代码与七家银行的名称框架，不包含私有 Excel 的研究文字、版本记录或截图。完整研究资料可通过侧栏「导入研究资料」选择本地 JSON 文件，在浏览器内导入，不会自动上传到 GitHub。资料文字与草稿保存在 localStorage，截图保存在 IndexedDB。

AI 请求会把当前结论与当前项目所引的最近 20 条观察文字发送到服务端配置的 AI 提供商；不会发送截图。

## 启动

需要 Node.js 22 或以上，无第三方运行依赖。

```sh
cp .env.example .env
npm start
```


## 真实 AI

在本机或部署服务的环境变量中设置 `OPENAI_API_KEY`，默认模型为 `gpt-4.1-mini`。可通过 `AI_MODEL` 和 `AI_BASE_URL` 使用兼容 Chat Completions 且支持 JSON 输出的服务。不要把密钥写入前端文件或提交到 GitHub。

AI 收到当前银行、研究问题、用户结论和当前项目引用的最近 20 条观察文字，不上传截图。接口返回独立的优化结论与补充内容，提示来源并区分事实、推测及待验证效果。

没有密钥时接口明确提示「服务尚未配置」，仍可用「本地参考」生成规则参考，也可继续编辑保存。当前仓库不包含 API 密钥，真实模型生成需部署者配置后验证。

默认仅监听本机。若通过 `HOST=0.0.0.0` 部署到远程服务器，应把服务置于已有访问控制的内部环境，接口本身不提供账户登录。GitHub Pages 只能展示静态编辑功能，无法运行 Node AI 接口；完整 AI 功能需要 Node 托管。

## 检查

```sh
npm run check
npm test
```

服务端测试覆盖成功生成、未配置密钥、无效输入、跨站请求、私有文件保护和上游失败。模型接口可注入模拟响应进行验证。

## 文件

- `index.html`、`styles.css`、`app.js`：界面、银行资料与交互。
- `evidence*.js`：从走查资料提取压缩后的原始截图；不写入浏览器本地存储。
- `server.mjs`：静态文件与 `/api/insights` 服务端接口。
- `.env.example`：环境变量模板，不含凭据。

本地数据不会跨浏览器或设备同步，清除站点数据会删除所保存的洞察。原始 Excel 没有加入仓库。
